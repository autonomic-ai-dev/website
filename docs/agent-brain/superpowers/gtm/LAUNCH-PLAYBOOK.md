# GTM launch playbook (90 days)

Operational checklist — not product strategy. Ship weekly; measure installs and `@starter` adds.

## Locked message (90 days — do not rewrite)

**Headline:** Route ~500 tokens from thousands of skills. Hooks enforce it. ~90–99% less input context vs loading everything.

**Proof points:**
- 30/30 Recall@3 on 2000 real skills.sh skills (CI)
- `agent-brain briefing` shows token savings per turn
- `install.sh --global --with-starter`
