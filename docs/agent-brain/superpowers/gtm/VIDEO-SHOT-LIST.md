# 3-minute demo shot list

Goal: before/after on **token cost + control**, not feature tour.

## Setup (off-camera)

- `install.sh --global --with-starter`
- Cursor Agent mode, hooks on
- Optional: fat `.cursorrules` or 20+ rule files for "before" contrast

## Act 1 — Before (45s)

| Shot | Audio |
|------|-------|
| Show bloated rules / large skill folder | "500 skills. Static rules say use X first." |
| Same task in Agent without agent-brain OR hooks off | Agent greps / wrong stack advice |
| Terminal: rough token estimate or "everything in context" | "Thousands of input tokens before the real task." |

## Act 2 — After (90s)

| Shot | Audio |
|------|-------|
| Enable agent-brain MCP | "Same repo. Same model." |
| Send: "optimize React server components" | |
| MCP panel: `route_task` → top skills | "Router picks 3 skills under budget." |
| Terminal: `agent-brain briefing` | Highlight **saved ~99%** line |
| Agent completes with loaded skill path | "Mandatory routing, not optional." |

## Act 3 — Proof + CTA (45s)

| Shot | Audio |
|------|-------|
| Browser: README benchmarks table | "30/30 on 2000 skills — CI gated." |
| `agent-brain registry list` | "@starter, @nextjs — one command." |
| Install one-liner on screen | CTA: GitHub link |

## B-roll

- `doctor --fix` (macOS codesign) — only if audience asks
- `add @nextjs` — stack wedge

## Export

- 1080p screen + mic
- Captions for token savings numbers
- Pin comment with install command + blog link
